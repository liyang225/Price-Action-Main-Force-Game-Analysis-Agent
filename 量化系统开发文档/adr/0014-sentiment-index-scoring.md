# 情绪指数分值：日上限 ±15，衰减系数 0.9，重大行情双向削减消息面

板块情绪指数是 0–100 的连续量，基准 50，跨交易日持久化并带惯性（ADR-0002）。本 ADR 定义它每日如何加减。

## 先钉边界：情绪指数不推导情绪周期档位

指数是连续量（用于观察程度与作为条件单元的分层维度），情绪周期档位是离散判断（由大模型输出、经混淆矩阵折算为对隐状态的观测证据）。**两者是独立字段。**

若用阈值从指数机械映射到档位，混淆矩阵与「大模型是噪声传感器」的整个设计一起作废（ADR-0001）。本 ADR 的分值不参与档位判定。

## 日变动配额

| 项 | 上限 |
|---|---|
| 日净增量 | ±15 |
| 消息面分项 | ±8 |
| 行情面分项 | ±15 |
| 单条消息 | ≤8 |

**日上限 ±15** 意味着从基准 50 走到极端需要 3–4 个交易日，符合钟摆节奏，同时防止单日跳到极值。单日反转由「政策环境」字段表达，不由情绪指数承担。

**行情面（±15）高于消息面（±8）**：行情增量按日收益率乘以 200 计算，并限制在 ±15；真金白银投出的票比新闻标题可信。这是分离均衡与混同均衡在分值上的体现。

**单条消息上限 8 低于日上限 15**，因此任何单条消息都无法独占当日变动空间。这是「不因一条消息扭转情绪」这条业务规则的量化表达。多条同向消息可累加，但受消息面分项 ±8 约束。

## 惯性用衰减系数，不用历史加权窗口

```
今日指数 = 50 + (昨日指数 − 50) × 0.9 + 当日净增量
```

只需保留昨日值，不维护历史序列。无新信息时偏离基准每日收敛一成，约 7 个交易日回到原偏离的一半。

历史加权窗口方案更灵活，但要维护序列，且窗口长度又是一个待定参数。

### 实现易错点

**无消息日不等于跳过情绪更新。** 某板块当日无消息命中时，消息增量为零，但**行情增量与衰减照常施加**。

写错的后果：缩量横盘的冷门板块情绪永久冻结在历史值上，因为它既没有消息也没有明显行情，程序若因「无消息」而跳过更新，衰减就永远不会发生。

## 重大行情双向削减消息面

触发条件：板块指数**单日跌超 5%** 或**两日累计跌超 8%**。

触发后消息面配额**减 60%**（±8 → ±3.2），行情面不变。

**削减对利好和利空双向作用。** 业务需求原话只提了「利好新闻影响甚微」，但利空也须削减——价格已经把利空定价了，此时再让消息面利空继续压低情绪，等于把同一个信息计了两次。

选择减 60% 而非清零，是因为极端行情下仍可能出现真正重要的消息（政策转向），完全失声的代价更大。

## 拒绝的方案

- **用阈值从情绪指数映射到情绪周期档位**：作废混淆矩阵设计
- **历史加权窗口实现惯性**：需维护序列，且窗口长度是新的待定参数
- **重大行情下消息面清零**：政策转向类消息会被误压制
- **只削减利好**：利空的双重计数问题未解决
