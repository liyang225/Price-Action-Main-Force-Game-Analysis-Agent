# 情绪指数输入以规范板块代码、结构化消息和交易日为边界

板块情绪台账与 HMM 信念只使用富途行业板块 `sector_code` 作为身份；板块名称只负责显示和消息搜索。行情分项只读取 `index_source` 对应板块代码的日线并计算一日、两日收益，不接受 PA 个股或大盘材料中的通用 `daily_return`。交易所日历未确认当日开市时，指数保持不变且不写台账。

基本面分值只在板块首次建档时作为初始先验，之后不按季度自动重锚；重锚会破坏跨日序列可比性，若需要必须另立版本化迁移决策。政策环境只修正参与者行为概率，不直接加减情绪指数；流动性环境与交易环境在形成可审计分值规则前也不进入指数。

消息预取保留原始 `NewsItem`，随后生成结构化消息事件，记录相关性、有效性、来源可信度、情绪分、主体目的和事件指纹。重复事件先去重，单条事件按配置完成分值转换并受 `single_news` 配额约束。情绪广度只聚合当前在册板块；在册板块尚未全部产生指数或周期位置时必须返回部分覆盖状态，不得把历史台账全集冒充当前广度。
