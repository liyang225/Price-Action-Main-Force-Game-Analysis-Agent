# 提示词 txt 文件统一存放路径，使用手册列出所有路径

所有大模型提示词（推演思路、参与者识别、人设与思维方式）存放在项目目录 `prompt_engine/` 下，按参与者类型分子目录。使用手册必须列出所有提示词文件路径，方便运营者调优。

## 目录结构约定

```
prompt_engine/
  操纵型主力/
    建仓.txt
    震仓.txt
    拉升.txt
    出货.txt
    观望.txt
    狩猎止损.txt
  配置型主力/
    建仓.txt
    ...
  羊群散户/
    ...
  通用/
    参与者识别.txt        # 区分识别参与者，第一步路由用
    人设与思维方式.txt    # 注入所有推演步骤的基础人设
    主体目的分析.txt      # 消息背后发布方意图判断
    情绪周期判断.txt      # 大模型输出情绪档位标签
```

## 路由映射表

路由从 `(情绪周期位置, 参与者类型)` 到提示词文件路径，存放在 `config/prompt_routing.yaml`，不硬编码在程序中（见 ADR-0005）。

## 当前状态

截至架构设计完成，所有提示词 txt 文件内容为空，尚未正式编写。路径结构已约定，提示词编写是 P2 阶段（推演引擎）的核心工作。编写时参考：
- 博弈论推演行为指导文档
- 霍华德马克斯二阶思维、钟摆理论参考
- PA_Agent 的人设与思维方式提示词作为格式参考

## 不可变规则

大模型永远只能访问 `prompt_routing.yaml` 映射表中已登记的文件路径。程序在加载时校验所有路径存在，大模型在运行时拿不到超出合法集合的文件名。
