# 博弈信号参数按 A 股 K_120M 实测分布重新校准

ADR-0016 末尾明确："任何参数在 A 股 K_120M 上跑出实测分布后，都应该按实测重新校准，而不是继续沿用加密市场的优化结果。"本 ADR 完成第一次校准。`signals.yaml` 版本 2 → 3。

## 一、实测方法与数据

| 项 | 取值 |
|---|---|
| 标的池 | 60 只 A 股（12 个行业板块 × 各板块流通市值前 5，与行为标注器研究共用池） |
| 数据 | 富途 OpenD `K_120M`，2020-01 至 2026-08 |
| 样本量 | 190,428 根 K_120M（约 9.5 万交易日） |
| 评估标准 | 信号对未来收益的**预测力**，非频率本身 |

评估指标：信号触发组 vs 未触发组的**前向收益差**（ret_gap）、**方向准确率**、**触发频率**（作约束）。前向窗口取 2 / 4 / 8 根 K_120M（约 1 / 2 / 4 个交易日）。

实验脚本（可复现）：`.scratch/business-rules/signal-calibration/` 下的 `fetch_bars.py`（拉取缓存）、`evaluate.py`（预测力评估，支持 `--override` 参数覆盖）、`smart_money_analysis.py`（聪明钱 z-score 扫描）。

## 二、校准结论（逐参数）

### 1. `smart_money` 判定逻辑：方向 → z-score（改代码）

**问题**：`positive = value > MA`（10 根均值）是"方向状态"，实测触发率 **48.7%**，接近 50% 的无信息量天花板；且 `absolute_threshold` 的量纲是成交量，跨股票不可通用（茅台成交数百亿 vs 小盘股数亿）。

**实测扫描**（`smart_money_analysis.py`）：

| z 阈值 | 触发频率 | w4 前向收益差 | w8 前向收益差 |
|---|---|---|---|
| 0.0（现状，value > MA） | 48.4% | +0.29% | +0.08% |
| 1.0 | 17.1% | +0.72% | +0.32% |
| **1.5** | **8.2%** | **+1.53%** | +0.69% |
| 2.0 | 3.2% | +0.43% | +0.47% |

**结论**：`positive` 改为「`value > MA` 且 `(value − MA) / std ≥ 1.5`」。z=1.5 是最优拐点——频率降到 8.2%（合理的事件频率），w4 预测力从 +0.29% 提升到 +1.53%（约 5 倍）。z=2.0 过严（捕捉的是极端超买，预测力反而回落）。

实现：`signals.yaml` 新增 `smart_money.positive_z_threshold: 1.5`，`game_signals.py::_passes_smart_money_threshold` 增加 z-score 分支。`null` 时保持旧的方向判定（向后兼容）。

### 2. `herd.rsi_overbought` 70 → 65

`herd_buying`（追涨羊群）在 A 股实测是**动量延续**信号（非反指），基线 w4 收益差 +1.61%。放宽到 65 后：触发率 0.19% → 0.46%，w4 收益差 +1.18%（保留），"频率 × 预测力"总信息量提升约 77%。

### 3. `herd.rsi_oversold` 保持 30（不放宽）

**这是校准中最重要的反向发现**。初版把 `rsi_oversold` 30 → 35 放宽，结果 `herd_selling`（超卖反弹）的方向准确率从 **62.2% 掉到 51.2%**，w4 收益差从 +1.31% 掉到 +0.11%。数据说明：**极超卖（RSI<30）才是超卖反弹信号有效的根源**，放宽会引入"不够超卖"的噪声，稀释预测力。

`herd_selling` 是当前最强的单信号：w4 +1.31%、w8 +1.68%、方向准确率 62~68%。它"稀"（0.069%）正是因为要求极超卖，而极超卖才有效——**物以稀为贵，不放宽**。

### 4. `nash.deviation` 2.0 → 1.5

基线纳什带 **88.6%** 时间在带内，导致动量、回归信号被整体压制。收窄到 1.5 后带内占比约 75%：`nash_reversion_buy` 方向准确率 45.9% → 50.4%（改善），动量信号频率提升 6 倍（但预测力本就弱，属中性结果）。

### 5. `liquidity_trap.psych_proximity` 0.01 → 0.02

`trap_up`（上方流动性陷阱=假突破回落）方向正确（基线 w2 收益差 -0.48%）。放宽后触发率 0.20% → 0.31%，方向准确率 52.5% → 54.2%（改善）。

## 三、附带发现（不在本次改动范围）

1. **`trap_down` 方向与文档语义相反**：文档语义是"下方流动性陷阱 = 主力猎杀止损后的反弹"（预期看涨），但 A 股实测触发后**继续下跌**（w2 收益差 -0.50%，方向准确率 43%）。这可能是 A 股无做空、止损盘行为与加密市场不同所致。**需单独 ADR 重审 `trap_down` 的语义**，不在本次参数校准范围。

2. **`contrarian` 极强但极稀**：`contrarian_buy` 仅 8 根样本（0.004%），w4 收益差 +3.72%、方向准确率 87.5%。它是"极超卖 + 吸筹/陷阱"的罕见组合，样本量不足以做统计推断，但方向性极强。本次不单独放宽（它依赖 `herd_selling`，而后者已决定不放宽）。

3. **`momentum_sell` 方向模糊**：基线 w2 收益差 +0.25%（预期为负），方向准确率 52~55%。它是弱信号，本次不单独处理。

## 四、保留的文档原值（未改）

| 参数 | 值 | 理由 |
|---|---|---|
| `herd.rsi_oversold` | 30 | 放宽会稀释最强信号 `herd_selling` 的预测力 |
| `herd.volume_multiple` | 2.0 | 文档原值，未发现校准依据 |
| `institutional.volume_multiple` | 2.5 | 文档原值 |
| `nash.period` | 16 | 8 个交易日锚点语义，未涉及 |
| 所有周期类参数 | 保持 | 日→K_120M ×2 换算规则不变 |

## 五、什么会让我推翻这些结论

1. 更长的样本（跨牛熊）或更多标的改变 z=1.5 的拐点位置。
2. 引入交易成本 / T+1 / 涨跌停约束后，部分信号的超额收益可能被吃掉。
3. `trap_down` 语义重审（第三条发现）完成后，可能连带调整 `liquidity_trap` 相关参数。
4. 前向收益窗口扩展到 T+5 以上时，动量类信号的持续性结论可能变化。

任何推翻都需递增 `signals.yaml` 的 version 并更新本 ADR。
