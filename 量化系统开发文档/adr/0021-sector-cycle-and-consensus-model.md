# 板块周期位置与共识状态分离

板块 HMM 的五个情绪周期位置改为冰点、启动、发酵、高潮、退潮。分歧不再是周期位置，因为它描述的是板块内多空博弈的瞬时共识状态，可在任何周期位置发生；它作为与周期位置正交的板块级字段保存，并以转强、转弱或未确认描述由分歧转一致的方向。

启动与发酵的边界不是固定连板数：启动是低位反转后趋势尚待确认，发酵要求上升趋势已确立且赚钱效应开始扩散。板块指数 OHLCV 可以在 v1 中提供趋势确认的价格代理，但不能验证成分股层面的赚钱效应扩散；v1 的发酵标签必须携带价格趋势代理的解释性元数据。

v1 只使用可完整取得的板块指数 OHLCV。缺少回看窗口、前视窗口或 v1 必需字段时，它返回 `data_insufficient`，不产出标签、不更新 C 矩阵，也不以另一版本的结果兜底。v2 现在设计并与 v1 影子并行运行；它从每日采集的板块成分股数据中计算趋势确认和扩散证据，包括连板高度、达到高度的股票数量及成分股占比、涨跌停原始计数、涨跌停平衡度、涨跌停活跃度及成交量相对前五日均值。

涨跌停比不作为原始指标。v2 保留涨停数和跌停数，并计算 `balance = (rise_limit - fall_limit) / (rise_limit + fall_limit)` 与 `activity = (rise_limit + fall_limit) / constituent_count`；分母为零时两项均为不可用，而非无穷大或人为上限。连板最高高度是领先证据，不能由单只股票单独决定板块周期位置或共识状态。

自动切换的全部条件必须随 v2 配置冻结：每个在册板块至少 5 个合格交易日、连续 3 个交易日影子运行没有结构性错误。合格交易日已定义为 v2 必需字段完整且可计算的一日，因此不另设重复的完整率门槛。满足条件后，系统自动全量重标所有可用历史、重建 v2 独立 C 矩阵计数、保存新规则哈希和切换报告，并以原子操作切换生产版本。新旧哈希、标签或 C 矩阵计数不得混用。

人工标注仍以目标日为单位：每个交易日按自己的回看窗口和前视确认窗口独立判定；后续走势仅用于确认该目标日，不能批量继承为发酵。既有的冰点、启动、退潮人工标签保留；旧抽样表按分歧均衡抽样，不能作为新五阶段的最终验证样本，须生成包含发酵的新盲样本。

HMM v3 是状态语义迁移，不继承旧分歧状态的标签计数或 C/W 后验。A 与 C 仍以五个有序周期位置的相邻转移和相邻误判作为未校准专家先验模板；发酵的 W 行则按“趋势已确认、上涨赚钱效应扩散”重新设定，提高拉升/跟随买入并降低出货/观望权重。全部数值仍标记为专家先验，待新状态空间积累独立标签后再校准。

连板高度不是固定阶段门槛，高潮和退潮也不由固定停留时长界定；后续量化口径见 ADR-0022。
