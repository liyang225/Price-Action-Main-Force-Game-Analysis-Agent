# PA Agent 界面组件沟通规范

> 状态：长期维护基准  
> 适用范围：所有桌面页面、弹窗、图表、配置页及其代码注释。  
> 维护原则：需求、实现或验收中出现的新组件，先使用本规范已有术语；确无对应术语时，在文末“变更记录”补充定义后再使用。

## 1. 沟通总则

1. 描述界面时使用“**页面 / 区域 / 容器 / 组件 / 子元素 / 状态**”五级定位，避免只说“这里”“那个按钮”。
2. 所有尺寸均使用 **px**，并明确作用对象：`容器外框`、`绘图区`、`内容区`、`控件本体` 不能互相替代。
3. 位置变更必须说明锚点和方向，例如“行情区整体相对主窗口上边沿上移 15px”；只说“上移”默认不包含相邻区域的连带移动。
4. 图表数据必须说明时间周期和范围。例如“15 分钟副图”指与 15 分钟 K 线逐根对齐的数据，不等同于当日累计行情数据。
5. 颜色修改必须说明作用范围：`文字名称`、`数值`、`描边`、`填充`、`曲线`、`悬浮态`。未说明时，不应连带修改其他范围。
6. “删除”指移除组件及其占位；“隐藏”指保留组件与逻辑但不显示；“禁用”指显示但不可交互。三者不得混用。
7. 需求涉及“全局”时，必须修改公共组件、公共样式或共享配置；不得为某个股票代码、某个窗口或单次数据写特例。

## 2. 页面与区域命名

| 标准名称 | 定义与边界 | 常见子元素 |
| --- | --- | --- |
| 主窗口 | 应用主界面可视范围，不包括操作系统标题栏与 Dock 栏 | 浏览器标签栏、主内容区、Dock 栏 |
| 浏览器标签栏 | 主窗口顶部用于切换页面/标签的容器 | 标签项、标签容器边框 |
| 主窗口交互栏 | 位于浏览器标签栏下方、包含“获取数据”“提交分析”等主操作的横向区域 | 主操作按钮、状态控件 |
| 行情信息栏（简称：行情栏） | 展示当前标的即时摘要信息的区域 | 标的名称、价格、涨跌幅、成交量、成交额 |
| 均线交互栏 | 行情栏下方的 K 线叠加指标控制区域 | MA 按钮、EMA 按钮、MA 配置项 |
| K 线主图（简称：主图） | 显示蜡烛图及其叠加线的图表容器 | 绘图区、价格坐标轴、时间轴、十字线 |
| 指标副图（简称：副图 / 长条图表） | 位于主图下方、与主图共享横向数据节点的指标图表容器 | 指标菜单容器、右侧数据区、绘图区、时间轴 |
| 自选股列表 | 展示用户自选标的的列表区域 | 名称列、代码列、涨跌幅列 |
| 分析池列表 | 展示待分析或分析中的标的列表区域 | 代码列、周期列、分析值列 |
| 决策页 | 展示诊断、趋势、阶段与交易决策的页面 | 趋势卡、周期卡、阶段卡、决策内容区 |
| Dock 栏 | 主窗口最底部的固定功能区域 | 状态与快捷操作 |

## 3. 通用容器结构与尺寸术语

```text
区域容器（外框）
├─ 标题/控制栏（可选）
│  ├─ 左侧控件
│  └─ 右侧数据区 / 工具按钮
├─ 分割线（可选）
└─ 内容容器
   └─ 绘图区 / 表格内容区 / 卡片内容区
```

| 术语 | 含义 |
| --- | --- |
| 外框尺寸 | 组件最外层 `QWidget/QFrame` 的宽高，含边框与内边距。 |
| 内容区 | 去除标题栏、边框、内边距后的承载区域。 |
| 绘图区 | 图表坐标系实际画线、画柱、画 K 线的区域；不含坐标轴与控制栏。 |
| 标题/控制栏 | 容器顶部用于选择、设置、摘要显示的固定横条。 |
| 主图与副图分栏比例调节（简称：分栏调节柄） | 主图与副图之间的可拖拽垂直分隔柄；拖拽它会同步改变主图与副图的可用高度比例。 |
| 菜单容器 | 承载下拉选择框及其相关设置按钮的卡片外框；宽度变更默认指外框总宽度。 |
| 右侧数据区 | 控制栏中菜单容器右侧、显示当前指标拆分数据的文本区域。 |
| 固定间隔 | 两个相邻容器边缘之间由 layout margin 或 spacer 保证的距离，须注明 px。 |
| 分割线 | 独立的视觉线条，不以 margin 或空白替代；需注明保留、删除或颜色变化。 |

## 4. 图表组件规范

### 4.1 主图与副图的对齐

- “同步”指同一根 K 线的横向数据节点位置完全一致，滚动、缩放和竖向十字线也必须同步。
- 主图与副图的**左侧绘图区/纵轴基线**对齐，不以容器最左边缘或右侧留白作为对齐依据。
- “调整图表高度”默认调整绘图区纵向高度；除非明确提出，不改变左右绘图留白、坐标轴宽度或数据范围。
- 副图默认绘图区高度为 **160px**（不含 34px 标题/控制栏）；用户可通过主图与副图分栏比例调节改变高度，程序不得在窗口缩放后覆盖该手动比例。
- 副图横轴可显示轴线，但默认不显示刻度文字；其刻度位置与主图横轴一致。
- 主图悬浮时：竖向虚线贯穿主图和副图；副图悬浮时：只显示竖向虚线。是否显示数值提示须单独说明。

### 4.2 主图与副图指标

| 标准名称 | 说明 |
| --- | --- |
| MA | 简单移动平均线。主图 MA 按钮只显示 `MA`，无下拉箭头；点击后进入/打开 MA 选择。 |
| EMA | 指数移动平均线。与 MA 按钮同尺寸。 |
| 成交量 | 副图默认指标，单位显示为“万”；计算和显示采用同一原始周期数据。 |
| 成交额 | 副图可选指标，显示采用同一原始周期数据；单位规则需在需求中明确。 |
| KDJ | 三条线：K、D、J。右侧数据区的 K/D/J 名称颜色必须分别与绘制线颜色一致。 |
| MACD | 包含 DIF、DEA 线和 MACD 柱。DIF/DEA 名称颜色跟随对应线；MACD 柱因可能红绿变化，名称保持中性，除非另行指定。 |
| VOL MA | 成交量/成交额副图的移动平均线集合；可编辑默认周期，清空输入框即移除该周期。 |

### 4.3 数据与单位

- 副图取数优先级：当前 K 线周期序列 > 当前图表数据范围；不得将当日累计实时行情字段替换为单根周期 K 线数据。
- 仅修改单位文字时，必须保持原始数值和 MA 计算输入不变；如需换算数值，需求必须明确“数值换算”。
- 成交量、成交额、各 MA 均值必须从同一原始单位、同一数据序列计算，格式化只发生在展示阶段。
- 数值正确性需以“标的 + 周期 + 对应 K 线时间 + 原始值 + 展示值”核验，不能只按单一当日总值判断。

### 4.4 右侧数据区文字颜色

- “仅名称着色”指 `K`、`D`、`J`、`DIF`、`DEA`、`MA5` 等名称字符使用对应曲线颜色；名称后的数值、分隔符均保持标准前景色。
- 若图形本身无单一固定色（例如 MACD 红绿柱），其名称使用标准前景色。
- 不将名称颜色扩散到下拉框、菜单卡片、坐标轴或其他指标文字。

## 5. 控件与状态命名

| 标准名称 | 定义 |
| --- | --- |
| 主操作按钮 | 触发关键流程的按钮，例如“获取数据”“提交分析”。 |
| 图标按钮 | 只显示图标的操作按钮，例如设置；默认透明背景，除非悬浮/按下态。 |
| 下拉选择框 | 展开后在候选项中选择一个当前指标或选项的控件。 |
| 多选项 | 可同时启用多个值的选择控件，例如 MA5、MA10。 |
| 可编辑周期输入框 | 用于修改 MA 周期的文本输入框；清空表示删除该项。 |
| Switch 开关 | 布尔状态控件，包含 `switch-track`（轨道）与 `switch-thumb`（滑块）。 |
| 开启态 / 关闭态 | Switch 的已选中/未选中视觉与内部值必须一致；恢复配置时必须同步两者。 |
| 悬浮态 / 按下态 / 禁用态 | 鼠标悬停、点击中、不可交互的视觉状态，均与默认态分开定义。 |

## 6. 列表与表格规范

- 使用“列表名称 + 列名 + 位置”定位：例如“分析池列表的代码列右侧增加周期列”。
- 列宽变更应写为“某列增加/减少 Npx”，并说明是否保持表格总宽度不变。
- “左右两端对齐”指表格/列表首尾边界与相邻容器边框连接；若有间隙，需明确其固定间隔。
- 删除列时，应同时处理表头、数据模型、排序/筛选、空态占位与相关测试。

## 7. 决策页文字亮度规则

- `正常亮度`：使用标准前景色 `T.FG`，适用于中性但有效的信息，如“趋势：震荡”“阶段：稳定”。
- `弱化亮度`：使用次级/三级前景色，仅适用于辅助说明、未提供的数据或不可操作信息。
- `语义色`：上涨/偏多使用市场上涨色；下跌/偏空使用市场下跌色；过渡/风险使用警示色。
- “趋势”“阶段”的标签与其值属于同一信息单元；当有有效中性数据时不得以弱化亮度显示。

## 8. 代码注释与实现命名

1. Python 变量、方法、对象名使用英文语义命名；面向用户的控件文字、文档术语使用本规范中文名称。
2. 代码注释优先说明“为何如此”，不重复代码字面行为。
3. 图表逻辑注释必须注明数据顺序（例如 `newest-first`）和单位是否仅展示格式化。
4. 对齐、尺寸或固定间隔类常量需要写清锚点与对象，例如：`INDICATOR_PANEL_HEIGHT_PX = 200`。
5. 不为单一标的写分支；若确有数据源差异，必须以数据源能力或时间周期为条件，并在注释中说明。

## 9. 需求描述模板

```text
[页面/区域]：
[目标组件]：
[当前问题或现状]：
[具体修改]：位置 / 尺寸 / 颜色 / 文案 / 交互 / 数据来源
[联动范围]：是否影响相邻容器、共享组件、全部窗口
[验收条件]：可观察的像素、状态、数据或行为结果
```

示例：

```text
[页面/区域]：主窗口 > 指标副图
[目标组件]：菜单容器
[具体修改]：外框总宽度缩短 15px；下拉框、设置图标和内边距随容器收缩，不影响右侧数据区起点以外的布局。
[联动范围]：所有分析窗口
[验收条件]：副图切换四种指标时菜单容器均比当前版本短 15px，文字不被截断。
```
