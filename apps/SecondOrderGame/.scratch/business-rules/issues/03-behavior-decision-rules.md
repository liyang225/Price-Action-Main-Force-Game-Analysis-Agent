# 06 — 六种主力行为的判定规则

Status: resolved

> 先读 `../BRIEFING.md`。本工单不重述背景。

**What to build:** 个股层事后标注器的核心：给定一只股票在第 t 个交易日的 OHLCV 加上后续 5 个交易日的数据，判定这天主力在做什么。六种行为各自的可程序验证条件与阈值。

六种行为是 `建仓 | 震仓 | 拉升 | 出货 | 观望 | 狩猎止损`，枚举已冻结，不要增删改名。

**最难的一处是震仓与狩猎止损的区分。** 两者都表现为先跌后涨，如果分不开，这两列计数会互相污染，而它们在博弈含义上完全不同——震仓是洗出不坚定筹码，狩猎止损是主力主动打穿支撑触发止损单、在下方接恐慌筹码。一个可能的切入角度是形态维度不同（横向震荡 vs 纵向插针、是否击穿关键位、下影线占振幅的比例、低点附近是否放量），但这只是起点，需要你在真实数据上找到能稳定分开的特征。

也要注意判定区之间的**空档与重叠**。六种行为的条件如果各自独立设阈值，很容易出现某类交易日同时满足两个条件（重叠）或掉进任何条件都不覆盖的缝隙（空档）。重叠交给工单 04 处理，空档留给工单 05，但你需要在报告里指出它们在哪里，而不是让下游自己去发现。

前向收益用什么基准由工单 02 决定，本工单直接采用其结论。

**这些规则一旦冻结，改动会作废全部累积标签计数**，所以每条规则都要附「什么证据会让我推翻它」。

**Blocked by:** 01 — 研究数据底座, 02 — 前向收益的基准

- [x] 六种行为各自的判定条件，用可程序验证的形式表达（指标 + 比较 + 阈值）
- [x] 所有阈值外置到配置，不写死在代码里
- [x] 震仓与狩猎止损的区分特征，并给出实测的误分比例
- [x] 在历史数据上跑出六种标签的分布，说明是否有某个标签占比畸高或畸低
- [x] 指出判定区的重叠处（哪些条件组合会同时命中）

- [x] 说明前视窗口长度是否需要按行为调整（例如出货可能比建仓需要更短的前视窗口）
- [x] 每条规则附「什么证据会让我推翻它」
