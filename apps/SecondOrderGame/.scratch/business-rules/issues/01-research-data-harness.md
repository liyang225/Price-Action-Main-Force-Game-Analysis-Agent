# 01 — 研究数据底座

Status: resolved

> 先读 `../BRIEFING.md`。本工单不重述背景。

**What to build:** 一个能拉历史数据、回放候选标注规则的研究工具，让后续工单可以用真实数据验证阈值而不是靠直觉猜。同时查清一个会影响多处设计的事实：富途实际能提供多深的历史数据。

给定一段历史区间、一批标的、一组判定条件，工具输出：各标签的命中次数与占比、同一交易日命中多个标签的频次、完全没有命中任何条件的交易日占比。改一个阈值就能重跑，不需要改代码。

历史深度这个事实要单独报告，因为它会反向影响「历史长度不足以识别模型参数」这一已冻结结论是否依然成立。如果富途能给的历史比预期深很多，某些被否决的方案值得重新评估——但那是负责人的决定，你只负责报告事实。

**Blocked by:** None — can start immediately

- [x] 能拉取个股与板块指数的历史 OHLCV，日线与 K_120M 两种周期
- [x] 报告实测的历史深度：个股 / 板块指数 × 日线 / K_120M 四个组合各自能回溯多久
- [x] 能加载一组用配置表达的判定条件并在历史区间上回放
- [x] 输出标签分布统计：每种标签的命中次数、占比
- [x] 输出多标签冲突频次：同一标的同一交易日命中 ≥2 个标签的次数与占比
- [x] 输出未命中率：不满足任何条件的交易日占比
- [x] 换阈值只需改配置，不需要改代码
- [x] 说明富途 OpenD 的可用性：是否需要账户权限、是否有调用配额、拉一年数据大约多久
- [x] 工具代码留在 `.scratch/` 下，不动 `src/`
