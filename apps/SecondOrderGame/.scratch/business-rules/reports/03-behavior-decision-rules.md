# 03 六种行为判定规则结论

## 结论

采用 YAML 中的六条候选规则和统一的五个交易日前视窗口：它们已能以相对板块收益回放并把震仓与狩猎止损在规则边界上完全分开，但在人工真值缺失前应视为待 ADR 冻结的定义，不应宣称为真实主力意图的准确识别。

## 证据

- 候选配置为 [`../experiments/config/behavior_rules.yaml`](../experiments/config/behavior_rules.yaml)，版本 `candidate-2026-08-10`，规则 SHA256 为 `d3e8759a1ba26faf66a6a8a1eef2d1db473f601ce65fd14c38be86cd2541f60a`。所有阈值均外置；修改配置即可重跑，配置载入会拒绝未知字段、非有限阈值和非布尔反转条件。
- `r1d` 为当日收益，`fwd5_rel` 为前向五日板块超额收益，`vol20` 为相对前 20 日成交量中位数，`支撑/阻力`为前 20 日低点最小值/高点最大值：

| 标签 | 可程序验证的全部条件 |
| --- | --- |
| 建仓 | `-2% <= r1d <= 2%`，`fwd5_rel >= 3%`，`vol20 <= 1.60`，收盘在当日振幅位置 `>= 0.45` |
| 震仓 | `r1d <= -2%`，`fwd5_rel >= 2%`，下影线/振幅 `>= 25%`，未来收盘最大反弹 `>= 3%`，支撑跌破 `> -0.5%`，`vol20 <= 1.20` |
| 拉升 | `r1d >= 3%`，`fwd5_rel >= 5%`，`vol20 >= 1.15`，收盘位置 `>= 0.60`，对前阻力突破 `>= 0` |
| 出货 | `-2% <= r1d <= 2%`，`fwd5_rel <= -3%`，`vol20 >= 1.20`，上影线/振幅 `>= 25%`，距前阻力 `>= -2%` |
| 观望 | `|r1d| <= 1%`，`|fwd5_rel| <= 2%`，`vol20 <= 1.30` |
| 狩猎止损 | `r1d <= -1%`，`fwd5_rel >= 1.5%`，支撑跌破 `<= -0.5%`，下影线/振幅 `>= 30%`，未来收盘最大反弹 `>= 2%`，`vol20 >= 1.20` |

- 有效样本 94,594 行上的原始候选命中为：建仓 4,292、震仓 561、拉升 479、出货 614、观望 19,401、狩猎止损 202。观望占 20.51%，其余非观望候选均低于 4.54%，因此“观望较多、其他行为较稀疏”是当前候选规则的真实分布，而不是遗漏的隐式兜底。
- 震仓与狩猎止损共同候选为 0；两者并集 763 行，规则级可检测的交叉污染率为 `0 / 763 = 0%`。这来自互斥的支撑边界和成交量方向，不是人工真值下的真实误分类率。没有人工逐日裁决标签，不能诚实地报告真实误分率。
- 原始规则仍有 13 个多命中行，全部为“建仓 + 狩猎止损”；有 69,058 个有效行未命中任何规则（73.00%），均由后续工单处理，而非藏进任一标签。
- 前视窗口统一为五个交易日，是为了让六类规则和工单 02 的基准可直接比较。现有数据没有独立的人工意图真值，不能可靠地证明“出货应短于建仓”等差异化窗口；当前不按行为调窗口，避免把同一数据上的规则调参误当验证。
- 异常数据处理：复权价格由数据源按前复权取得；零振幅 K 线的影线/实体比设为 0、收盘位置设为 0.5，避免无穷值；若前视五日内股票停牌，窗口不再延长到五根后续股票 K 线，而是直接无标签；缺失板块或前向数据也不产生标签。涨跌停和除权日当前保留真实价格行为，尚无单独交易日历标记，不能声称已完成异常日识别。

每条规则的可推翻证据如下：建仓若人工复核显示低量横盘后的相对上涨不对应持续吸筹；震仓若未破支撑的下跌反弹大多是正常波动；拉升若突破前阻力后的超额上涨没有持续性；出货若近阻力长上影和放量后的跑输并不集中于筹码派发；观望若其样本出现系统性主动成交结构；狩猎止损若真值事件常不击穿支撑或不伴随下方承接放量。任一证据须在新版本规则、独立留出时期和人工审计上复现，才可改阈值。

## 权衡

规则选择可审计、可复跑和低调参自由度，代价是覆盖率只有 26.99%，并且前向结果是事后定义的一部分。没有使用黑箱分类器、概率打分或随品种自适应阈值，因为这些会与冻结的“标注器是确定性定义、不可随意改动”原则冲突，也无法在无真值时验证。

## 什么会让我推翻这个结论

建立跨行业、跨市场状态的人工复核集后，若规则级交叉污染低但真实混淆率仍高，或五日窗口在留出时期的稳定性显著低于替代窗口，应按 ADR 建新版本、全量重标并重建 W 计数。若单一类别在滚动样本中长期接近零或占绝对多数，也说明阈值失衡。

## 已知未解

当前样本有幸存者和当前市值前视偏差，且没有独立意图真值；所有“行为”仍是可验证的事后定义。`docs/adr/0007-labeler-day0-independent-freeze.md` 的旧五标签枚举与共享简报的冻结六标签不一致，本工单按简报执行，但该 ADR 需要负责人另行修正。
