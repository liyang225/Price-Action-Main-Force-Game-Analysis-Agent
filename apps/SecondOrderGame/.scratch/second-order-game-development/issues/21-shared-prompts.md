# 21 — 编写通用提示词

**What to build:** 编写参与者识别、人设与思维方式、主体目的分析和情绪周期判断四套通用提示词，使模型在固定职责内输出可校验的离散结果。

**Blocked by:** 19 — 实现安全的提示词路由器.

**Domain decision:** 周期位置只可输出冰点、启动、发酵、高潮、退潮。板块共识状态独立输出一致/分歧及转强/转弱/未确认，不能把分歧作为周期位置。平台整理、二次启动等结构变化通过正交的 `cycle_event` 输出，不新增周期位置；高潮后平台未破归发酵，向下破位并扩散转弱才归退潮。

**Status:** ready-for-agent

- [x] 四套提示词都明确禁止模型生成概率、计算博弈信号或选择文件路径。
- [x] 输出字段使用项目领域词汇和固定枚举，可被结构化校验器拒绝非法值。
- [x] 示例覆盖正常、证据不足和冲突证据场景，并与二方参与者模型一致。

**完成情况:**
已完成四套通用提示词的编写:
1. `通用/参与者识别.txt` - 判断主力/散户,输出固定枚举值
2. `通用/人设与思维方式.txt` - 二阶博弈推演的方法论与立场
3. `通用/主体目的分析.txt` - 识别消息发布方的真实意图
4. `通用/情绪周期判断.txt` - 输出五档情绪位置(冰点/启动/发酵/高潮/退潮)

所有提示词均:
- 明确禁止输出概率数字、博弈信号数值和文件路径选择
- 使用固定枚举值和结构化JSON输出格式
- 包含完整的示例和证据权重说明
- 与ADR-0021(二方参与者模型)保持一致
