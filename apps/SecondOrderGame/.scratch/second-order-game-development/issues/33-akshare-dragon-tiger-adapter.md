# 33 — 接入 AkShare 龙虎榜

**What to build:** 通过统一市场数据边界获取指定股票和日期的龙虎榜记录，为后续机构与游资观测提供稳定输入。

**Blocked by:** 02 — 建立统一市场数据接缝.

**Status:** ready-for-human

- [x] 给定股票与日期能在 30 秒内返回龙虎榜记录或明确无数据状态。
- [x] AkShare 错误、字段变化和空结果被适配为稳定业务语义。
- [x] 接入不依赖申万行业分类，也不引入北向资金数据。
