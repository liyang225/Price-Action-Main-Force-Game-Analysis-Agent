【文件定位】主力-狩猎止损行为推演 - 板块退潮期,主力猎杀止损单获取流动性的行为逻辑与特征识别。

【加载前提】
- 周期位置: 退潮 (主要) 或 冰点/启动 (次要)
- 参与者类型: 主力
- 人设与思维方式: 已加载

【行为定义】
狩猎止损: 主力主动驱动价格触发散户止损单,在下方接收恐慌抛售的筹码。三阶段行为: 探测→触发→接收。

【周期背景: 退潮期】
- 市场情绪: 恐慌蔓延,追高者被套
- 散户状态: 止损单密集,"侥幸"心理未离场
- 主力优势: 知道止损位置,可以主动触发
- 时机: 高位派发完成后,或跌势中继

【三阶段行为特征】

**阶段1: 探测止损密集区**
- 特征: 小幅试探性下跌,测试支撑位
- 资金: 小单量卖出,试探市场反应
- 价格: 逼近关键支撑位,但未破
- 目的: 确认止损单密集程度
- 时间: 1-2日

**阶段2: 驱动价格触发止损**
- 特征: 主动砸盘,快速跌破支撑
- 资金: 大单快速流出,制造恐慌
- 价格: 快速下跌,跌破关键支撑/心理价位
- 目的: 触发止损单,制造抛压
- 时间: 数小时至1日
- 关键: 跌破幅度足够,但不过度

**阶段3: 接收恐慌筹码**
- 特征: 下方接盘,价格快速回升
- 资金: 大单快速流入,接收筹码
- 价格: 长下影线,快速收复部分失地
- 目的: 低价获取筹码
- 时间: 数小时至1日
- 关键: 回升速度快,V型反转

【完整特征识别】

**1. 资金特征**
- 阶段1: 小单卖出,试探
- 阶段2: 大单快速流出,砸盘
- 阶段3: **大单快速流入,接盘** (关键特征)
- 活跃度: 程序标记为短期暴增,但很快回落
- 时间跨度: 整个过程1-3日

**2. 价格特征**
- 快速跌破支撑: 跌破关键位或心理价位
- **长下影线**: 下方有强支撑,不是真实下跌
- V型反转: 快速回升,收复部分失地
- 时间短: 整个过程通常1-2日完成
- 关键: 跌破后**不持续下跌**

**3. 技术信号**
- **下方流动性陷阱触发**: 跌破支撑后快速回撤
- 止损狩猎信号: 三阶段特征完整
- 逆势买入信号: 羊群卖出 + 吸筹信号/下方流动性陷阱
- 成交量异常: 砸盘时放量,回升时缩量

**4. 消息面**
- 可能配合利空: 利用利空制造恐慌
- 或无消息砸盘: 纯技术性猎杀
- 关键: 利空不改变基本面

【二阶博弈推演】

**散户视角(一阶)**
- 看法: 支撑破了,要继续跌
- 行为: 止损离场,恐慌抛售
- 情绪: 恐惧,认亏离场

**主力视角(二阶)**
- 看到: 散户止损单密集在关键位下方
- 判断: 可以主动触发,低价获取筹码
- 策略:
  - 探测: 试探性下跌,确认止损密度
  - 触发: 快速砸盘,击穿支撑
  - 接收: 下方大单接盘,V型反转
- 目标: 用最小成本获取最多筹码

**散户再判断(三阶,少数)**
- 发现: 跌破后快速回升,下影线长
- 怀疑: 是否止损狩猎?
- 困境: 已经止损离场,后悔
- 结果: 少数理性者不设机械止损,躲过猎杀

**主力应对(四阶)**
- 策略: 收集完筹码后,可能快速拉升
- 目标: 让止损者高位追回,双重收割

【行为子类型】

**利用利空狩猎**
- 特征: 利空出现,配合砸盘
- 资金: 利空当日大单流出,次日流入
- 价格: 利空后快速下跌,随后V型反转
- 目的: 利用恐慌加速止损触发
- 后续: 利空消化后快速反弹

**纯技术性狩猎**
- 特征: 无消息,纯技术性砸盘
- 资金: 大单快速流出后流入
- 价格: 跌破技术支撑后快速回升
- 目的: 精准打击止损密集区
- 后续: 收集筹码后企稳或拉升

**跌势中继狩猎**
- 特征: 下跌趋势中的加速下跌
- 资金: 大单流出,但后续流入
- 价格: 加速下跌后企稳
- 目的: 清理最后的持仓者
- 后续: 可能进入冰点期

**双向狩猎**
- 特征: 先向上假突破,再向下砸盘
- 资金: 先流入诱多,后流出砸盘,最后流入接盘
- 价格: 冲高回落后快速下跌,随后回升
- 目的: 同时收割多头和空头止损
- 后续: 筹码充分换手后企稳

【与其他行为的区分】

| 行为 | 资金特征 | 价格特征 | 关键区别 |
|------|---------|---------|---------|
| 狩猎止损 | 大单流出后**快速流入** | 跌破后**V型反转** | 长下影线,1-2日完成 |
| 出货(打压) | 大单**持续流出** | 跌破后**继续下跌** | 不回升,持续多日 |
| 震仓 | 大单流出后回流 | 震荡后回升 | 启动/发酵期,时间较长 |
| 建仓 | 大单缓慢流入 | 横盘/阴跌 | 冰点期,不制造恐慌 |

【关键区分: 狩猎止损 vs 打压出货】

| 指标 | 狩猎止损 | 打压出货 |
|------|---------|---------|
| 大单在回升时 | ✓ 快速流入接盘 | ✗ 继续流出 |
| 价格是否V型反转 | ✓ 快速回升 | ✗ 持续下跌 |
| 下影线 | ✓ 长下影线 | ✗ 实体阴线 |
| 时间周期 | 1-2日完成 | 持续数日 |
| 后续走势 | 企稳或反弹 | 继续下跌 |

**判断方法**: 观察跌破后1-2日内大单是否流入,价格是否快速回升

【情景推演】

**情景A: 超预期(快速反弹)**
- 触发: 狩猎完成,大单接盘,快速回升
- 主力反应: 筹码收集完成,可能拉升
- 行为倾向: 转查建仓、拉升或观望
- 应对: 下影线低点是介入机会

**情景B: 符合预期(企稳横盘)**
- 触发: 狩猎完成,价格企稳
- 主力反应: 继续收集或观望
- 行为倾向: 建仓或观望为主,继续狩猎证据减弱
- 应对: 关注是否进入冰点期建仓

**情景C: 低于预期(继续下跌)**
- 触发: 跌破后未回升,继续下跌
- 主力反应: 实际是打压出货,非狩猎止损
- 行为倾向: 出货证据增强,重新核对狩猎假设
- 应对: 修正判断,警惕真实下跌

【关键识别指标】

**确认狩猎止损的证据链**
1. 周期位置: 退潮(主要)
2. 资金流向: 大单流出后**1-2日内快速流入**
3. 价格行为: 跌破支撑后**V型反转,长下影线**
4. 技术信号: 下方流动性陷阱 + 止损狩猎三阶段
5. 散户行为: 恐慌止损,抛售

**证据权重**
- 必要证据(缺一不可):
  - 跌破关键位 + 大单回流 + 价格快速回升
- 强化证据:
  - 长下影线 + 下方流动性陷阱 + 1-2日完成
- 排除证据(判定为出货):
  - 跌破后持续下跌 + 大单不回流

【狩猎完成的信号】

**筹码收集完毕的特征**
1. 大单持续流入: 接盘完成
2. 价格企稳: 不再下跌
3. 成交量萎缩: 恐慌情绪消退
4. 止损单清空: 抛压衰竭
5. 后续: 进入冰点建仓或直接拉升

【重要提醒】

**狩猎止损的本质**
- 不是随机下跌,是精准打击
- 目标是止损单密集区
- 时间短,效率高
- 完成后快速回升

**散户如何应对**
- 不设机械止损位(避免被精准打击)
- 关注下影线和大单回流
- 恐慌时不割肉,理性判断

**与"假突破"的区别**
- 假突破: 技术形态描述
- 狩猎止损: 主力意图,有明确目标(止损单)

【禁止事项】
1. 不输出概率数字(由HMM计算)
2. 不把所有下跌都归为狩猎止损
3. 必须验证大单是否回流(区分出货)
4. 不忽略三阶段特征的完整性
5. 不在阶段1或2就高置信度判断(需等阶段3确认)
