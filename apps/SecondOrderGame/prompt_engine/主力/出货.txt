【文件定位】主力-出货行为推演 - 板块高潮/退潮期,主力派发筹码的行为逻辑与特征识别。

【加载前提】
- 周期位置: 高潮 或 退潮
- 参与者类型: 主力
- 人设与思维方式: 已加载

【行为定义】
出货: 主力利用散户FOMO情绪和高位流动性,派发手中筹码,兑现利润。特征是隐蔽性与欺骗性并存。

【周期背景】

高位横盘本身不等于出货或退潮。若趋势、核心强度和赚钱效应未破，周期位置可保持为发酵，记录 `cycle_event=平台整理`；平台向上突破是 `二次启动`。只有出现高位兑现并向下破位、板块强度和赚钱效应扩散转弱时，才记录 `cycle_event=破位转弱` 并进入退潮。

**高潮期出货**
- 市场情绪: 极度乐观,FOMO追高普遍
- 散户状态: 疯狂追涨,接盘意愿极强
- 主力优势: 流动性充足,散户主动接盘
- 出货目的: 在最高流动性时兑现利润

**退潮期出货**
- 市场情绪: 恐慌开始蔓延
- 散户状态: 部分割肉,部分"侥幸"持有
- 主力困境: 流动性下降,出货困难
- 出货目的: 剩余筹码清理,不惜打压出货

【出货行为特征】

**1. 资金特征**
- 大单持续流出: super+big净流出
- 小单接盘: small净流入(散户接盘)
- 活跃度高: 使用程序注入的活跃度分档
- 关键特征: 大单流出 + 小单流入 = 派发

**2. 价格特征**
- 冲高回落: 盘中冲高但收盘回落
- 涨停打开: 冲击涨停后快速打开
- 上影线长: 上方抛压明显
- 高位放量滞涨: 成交量大但价格不再上涨

**3. 技术信号**
- 派发信号触发: AD线<20日均线 + 机构成交量
- 上方流动性陷阱: 向上假突破后快速回撤
- 逆势卖出信号: 羊群买入 + 派发信号
- 技术指标极值: 引用程序注入字段,并检查价格是否滞涨

**4. 消息面**
- 利好刷屏: 媒体狂热报道,吸引散户
- 主力配合消息: 借利好派发筹码
- 澄清公告可能出现: 前期传言被澄清

【二阶博弈推演】

**散户视角(一阶)**
- 看法: 趋势强劲,继续上涨
- 行为: FOMO追高买入
- 情绪: 极度乐观,害怕错过

**主力视角(二阶)**
- 看到: 散户FOMO,接盘意愿极强
- 判断: 最佳出货时机,流动性充足
- 策略:
  - 高位派发: 借利好和涨停吸引接盘
  - 制造假象: 拉升诱多,实则出货
- 目标: 在最高价位清空筹码

**散户再判断(三阶)**
- 发现: 涨停打开,冲高回落
- 怀疑: 是否见顶?
- 困境: FOMO情绪 vs 理性判断
- 结果:
  - 少数理性者: 减仓离场
  - 多数FOMO者: 继续持有或加仓

**主力应对(四阶)**
- 策略: 继续制造上涨假象,维持散户信心
- 手段: 尾盘拉升,次日高开,但持续派发
- 目标: 直到筹码派发完毕

【行为子类型】

**高位派发(高潮期主导)**
- 特征: 高位横盘或缓慢上涨,大单持续流出
- 资金: 大单流出,小单接盘,换手率极高
- 价格: 冲高回落,上影线长
- 目的: 利用FOMO在最高价位派发
- 后续: 派发完成后价格崩塌

**借利好出货**
- 特征: 利好当日大涨或涨停,但大单流出
- 资金: 利好前大单已流出,利好后小单接盘
- 价格: 涨停打开,冲高回落
- 目的: 利用利好吸引接盘,加速派发
- 后续: 利好效应消退后快速下跌

**打压出货(退潮期主导)**
- 特征: 主动砸盘,不惜低价出货
- 资金: 大单快速流出,小单恐慌割肉
- 价格: 快速下跌,连续阴线
- 目的: 剩余筹码清理,流动性不足时被迫低价
- 后续: 加速下跌,可能触发止损狩猎

**尾盘拉升次日出货**
- 特征: 尾盘拉升制造上涨假象,次日高开出货
- 资金: 尾盘小单量拉升,次日大单流出
- 价格: 尾盘拉高,次日高开低走
- 目的: 制造次日高开机会,吸引散户接盘
- 后续: 次日高开低走,派发完成

【与其他行为的区分】

| 行为 | 资金特征 | 价格特征 | 周期 |
|------|---------|---------|------|
| 出货 | 大单流出,小单接盘 | 冲高回落,涨停打开 | 高潮/退潮 |
| 拉升 | 大单流入,小单跟随 | 明显上涨,创新高 | 发酵/高潮 |
| 震仓 | 大单流出后回流 | 大幅震荡后回升 | 启动/发酵 |
| 狩猎止损 | 大单流出后流入 | 快速下跌后回升 | 退潮 |

【关键区分: 出货 vs 震仓】

**出货特征**
- 大单流出后**不回流**
- 价格下跌后**不回升**
- 换手率持续高位
- 周期: 高潮/退潮

**震仓特征**
- 大单流出后**快速回流**
- 价格下跌后**快速回升**
- 换手率短期放大后回落
- 周期: 启动/发酵

**判断方法**: 观察后续2-3根K线,大单是否回流

【情景推演】

**情景A: 超预期(继续上涨)**
- 触发: 新增重磅利好,散户继续追高
- 主力反应: 继续借利好派发,或暂停出货
- 行为倾向: 继续出货为主,保留短暂拉高分支
- 应对: 警惕最后一波拉升,不追高

**情景B: 符合预期(高位震荡)**
- 触发: 高位横盘,散户观望
- 主力反应: 继续派发,制造上涨假象
- 行为倾向: 继续派发为主,观望为次
- 应对: 高位不接盘,等待明确转折

**情景C: 低于预期(开始下跌)**
- 触发: 利空出现或技术破位
- 主力反应: 加速出货,可能打压
- 行为倾向: 偏打压出货,同时检查狩猎止损证据
- 应对: 快速离场,不抱侥幸心理

【关键识别指标】

**确认出货的证据链**
1. 周期位置: 高潮或退潮
2. 资金流向: 大单流出 + 小单流入
3. 价格行为: 冲高回落 / 涨停打开 / 高位滞涨
4. 技术信号: 派发信号 + 上方流动性陷阱
5. 散户行为: FOMO追高 / 侥幸持有

**证据权重**
- 必要证据:
  - 高潮/退潮期 + 大单流出 + 小单接盘
- 强化证据:
  - 派发信号 + 涨停打开 + 换手率极高
- 排除证据(可能是震仓):
  - 大单快速回流 + 价格快速回升

【出货完成的信号】

**筹码派发完毕的特征**
1. 大单流出减少: 已无筹码可派发
2. 成交量萎缩: 流动性下降
3. 价格快速下跌: 无支撑
4. 散户被套: 追高者全部亏损
5. 后续: 进入退潮期,可能触发止损狩猎
