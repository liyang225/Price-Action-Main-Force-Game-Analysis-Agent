【文件定位】主力-震仓行为推演 - 板块启动/发酵期,主力洗盘清洗浮筹的行为逻辑与特征识别。

【加载前提】
- 周期位置: 启动 或 发酵
- 参与者类型: 主力
- 人设与思维方式: 已加载

【行为定义】
震仓: 主力在建仓完成后拉升前,通过制造恐慌清洗浮筹,降低后续拉升成本,同时测试散户信心。

【周期背景】

**启动期震仓**
- 市场情绪: 从悲观转中性,半信半疑
- 散户状态: 观望为主,持仓不坚定
- 主力目的: 测试抛压,清洗跟风盘
- 时机: 底部反弹后,趋势未确认

**发酵期震仓**
- 市场情绪: 乐观情绪扩散,但未FOMO
- 高位平台整理不自动等同于震仓;只有出现短期洗盘、支撑守住且资金快速回流时才记录震仓
- 散户状态: 开始跟风,但部分不坚定
- 主力目的: 清洗获利盘,降低拉升阻力
- 时机: 上涨中继,技术回调

【震仓行为特征】

**1. 资金特征**
- 大单短期流出: 主力主动制造恐慌
- **关键: 随后大单快速回流** (与出货的核心区别)
- 小单恐慌割肉: 散户被洗出去
- 换手率短期放大: 2-4%,但很快回落
- 时间: 震仓通常1-3日,不超过5日

**2. 价格特征**
- 大幅震荡: 快速下跌后快速回升
- 跌破支撑后回升: 向下假突破趋势线/均线
- 长下影线: 下方有支撑,不是真实下跌
- **关键: 快速收复失地** (与出货的核心区别)
- 不破关键位: 守住重要支撑位

**3. 技术信号**
- 可能触发流动性陷阱: 向下假突破后快速回撤
- 止损狩猎特征: 探测止损密集区后回升
- 均线支撑: 回调至EMA20后企稳
- 趋势线不破: 仍在上升通道内

**4. 消息面**
- 利空不改基本面: 短期扰动,非实质利空
- 无消息自然回调: 技术性回调
- 后续利好可能配合: 震仓后利好助推拉升

【二阶博弈推演】

**散户视角(一阶)**
- 看法: 趋势破了,要跌了
- 行为: 恐慌割肉,或止损离场
- 情绪: 恐惧,后悔追高

**主力视角(二阶)**
- 看到: 跟风盘不坚定,获利盘涌出
- 判断: 需要清洗浮筹,降低拉升阻力
- 策略:
  - 制造恐慌: 主动砸盘或配合利空
  - 测试支撑: 探测散户止损位
  - 快速回升: 不让筹码流失太多
- 目标: 清洗不坚定持仓,留下坚定看多者

**散户再判断(三阶,少数)**
- 发现: 下跌无量,下方有支撑
- 怀疑: 是否洗盘?
- 困境: 恐惧 vs 理性判断
- 结果:
  - 理性者: 持股不动或低位加仓
  - 恐慌者: 割肉离场(被洗出去)

**主力应对(四阶)**
- 策略: 快速收复失地,让割肉者后悔
- 目标: 完成洗盘后继续拉升

【行为子类型】

**技术回调震仓(发酵期主导)**
- 特征: 上涨中继自然回调
- 资金: 大单短期流出后快速回流
- 价格: 回调30-50%涨幅,不破趋势线
- 目的: 清洗获利盘,健康回调
- 后续: 回调完成后继续拉升

**制造恐慌震仓(启动期主导)**
- 特征: 主动砸盘,快速下跌
- 资金: 大单主动流出,小单恐慌
- 价格: 跌破支撑位,触发止损后快速回升
- 目的: 测试散户信心,清洗跟风盘
- 后续: 快速收复,进入拉升阶段

**配合利空震仓**
- 特征: 利空出现,价格下跌
- 资金: 利空当日大单流出,次日回流
- 价格: 利空当日下跌,后续快速回升
- 目的: 利用利空制造恐慌,加速洗盘
- 后续: 利空效应消退,继续上涨

**反复震仓**
- 特征: 多次震荡洗盘,上涨途中反复
- 资金: 大单反复流出流入
- 价格: 箱体震荡,不破下沿不创新高
- 目的: 彻底清洗浮筹,磨散户耐心
- 后续: 震仓充分后突破拉升

【与其他行为的区分】

| 行为 | 资金特征 | 价格特征 | 关键区别 |
|------|---------|---------|---------|
| 震仓 | 大单流出后**快速回流** | 快速下跌后**快速回升** | 时间短(1-3日),可恢复 |
| 出货 | 大单流出**不回流** | 下跌后**不回升** | 持续流出,价格崩塌 |
| 建仓 | 大单缓慢流入 | 横盘/阴跌 | 冰点期,不拉升 |
| 狩猎止损 | 大单流出后流入 | 快速下跌后回升 | 退潮期,触底反弹 |

【关键区分: 震仓 vs 出货】

**判断方法: 观察后续2-3根K线**

| 指标 | 震仓 | 出货 |
|------|------|------|
| 大单是否回流 | ✓ 快速回流 | ✗ 不回流 |
| 价格是否回升 | ✓ 快速回升 | ✗ 不回升 |
| 时间周期 | 1-3日 | 持续数日 |
| 周期位置 | 启动/发酵 | 高潮/退潮 |
| 技术位置 | 趋势线支撑 | 高位滞涨 |

**震仓的必要条件**
1. 大单在2-3日内回流
2. 价格快速收复失地
3. 周期: 启动/发酵期(非高潮/退潮)

**如果不满足上述条件 → 判定为出货,非震仓**

【情景推演】

**情景A: 超预期(利好出现,快速回升)**
- 触发: 利好催化,散户信心恢复
- 主力反应: 震仓完成,快速拉升
- 行为倾向: 震仓完成后偏向拉升
- 应对: 震仓低点是介入机会

**情景B: 符合预期(震荡整理)**
- 触发: 继续横盘震荡
- 主力反应: 继续震仓,反复洗盘
- 行为倾向: 继续震仓为主,保留观望或拉升分支
- 应对: 耐心等待震仓完成,不被洗出

**情景C: 低于预期(破位下跌)**
- 触发: 利空叠加或技术破位
- 主力反应: 暂停拉升计划 或 转为出货
- 行为倾向: 震仓假设减弱,转查出货、建仓或观望
- 应对: 警惕震仓失败转为出货,观察大单是否回流

【关键识别指标】

**确认震仓的证据链**
1. 周期位置: 启动或发酵
2. 资金流向: 大单流出后2-3日内回流
3. 价格行为: 快速下跌后快速回升
4. 技术信号: 趋势线支撑 / 流动性陷阱
5. 散户行为: 恐慌割肉

**证据权重**
- 必要证据:
  - 启动/发酵期 + 大单回流 + 价格回升
- 强化证据:
  - 流动性陷阱 + 趋势线支撑 + 1-3日完成
- 排除证据(可能是出货):
  - 高潮/退潮期 + 大单不回流 + 持续下跌

【震仓完成的信号】

**洗盘结束,准备拉升的特征**
1. 大单持续回流: 重新开始流入
2. 价格收复失地: 回到震仓前价位
3. 换手率回落: 恐慌情绪消退
4. 浮筹清洗完毕: 成交量萎缩
5. 后续: 突破震仓箱体,进入拉升

【禁止事项】
1. 不输出概率数字(由HMM计算)
2. 不输出具体价格目标

5. 不忽略周期位置(高潮期的"震仓"多为出货假象)
