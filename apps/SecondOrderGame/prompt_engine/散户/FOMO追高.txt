【文件定位】散户-FOMO追高行为推演 - 板块高潮期,散户情绪驱动的非理性追涨行为逻辑与特征识别。

【加载前提】
- 周期位置: 高潮 (主要) 或 发酵后期 (次要)
- 参与者类型: 散户
- 人设与思维方式: 已加载

【行为定义】
FOMO追高: Fear Of Missing Out,散户因害怕错过机会而在高位情绪化买入,是非理性行为的典型。

【周期背景: 高潮期】
- 市场情绪: 极度乐观,FOMO情绪普遍
- 散户状态: 疯狂追涨,all in入场
- 主力状态: 正在出货,利用散户接盘
- 关键特征: 赚钱效应极强,媒体狂热报道
- 高潮后的高位平台若趋势和核心未破,周期位置可回到发酵而非自动退潮;向上突破形成 `cycle_event=二次启动` 时,错过者可能再次FOMO追高

【FOMO追高特征】

**1. 资金特征**
- **小单疯狂流入**: 使用程序注入的小单主导分档
- 大单流出: 主力派发,散户接盘
- 活跃度暴增: 使用程序注入的极端活跃分档
- 资金流对比: 大单流出 + 小单流入 = 派发
- 追涨盘特征: 市价单追高,不计成本

**2. 价格特征**
- 连续涨停或大涨: 短期涨幅巨大
- 加速上涨: 涨幅斜率陡峭
- 高位放量滞涨: 成交量极大但涨幅收窄
- 冲高回落: 盘中冲高,收盘回落
- 上影线增多: 上方抛压开始显现

**3. 技术信号**
- **羊群行为触发**: 只引用程序注入的羊群行为布尔信号,不重算公式或阈值
- 派发信号: AD线<20日均线 + 机构成交量
- 逆势卖出信号: 羊群买入 + 派发信号
- 技术极值: 引用程序注入的技术极值与动量偏离字段

**4. 情绪与消息面**
- 媒体狂热报道: 利好刷屏,到处讨论
- 社交媒体热度: 相关话题冲上热搜
- 群体传染: "不买就亏了"的心态蔓延
- 利好频出: 各种利好(真假混杂)密集发布

【二阶博弈推演】

**散户视角(一阶)**
- 看法: 趋势强劲,继续上涨,不买就错过
- 行为: 不计成本追高买入,甚至加杠杆
- 情绪: 极度乐观,FOMO主导,贪婪
- 心理: "大家都在买", "已经涨这么多了,再涨一倍"

**主力视角(二阶)**
- 看到: 散户FOMO,接盘意愿极强
- 判断: 最佳出货时机,流动性充足
- 策略: 借散户FOMO派发筹码
  - 制造上涨假象: 尾盘拉升,次日高开
  - 借利好出货: 利好当日涨停打开
  - 持续派发: 高位横盘,不断出货
- 目标: 在最高价位清空筹码

**理性散户(三阶,少数)**
- 发现: 大单流出,小单接盘,技术超买
- 判断: 主力在出货,散户接盘
- 行为: 拒绝追高,甚至减仓离场
- 结果: 躲过顶部,保住利润

**FOMO散户后续(四阶)**
- 现实: 买入后快速被套
- 心理: 从贪婪转为恐惧,"侥幸"不割肉
- 行为: 继续持有,等待解套(但大概率解不了)
- 结果: 进入退潮期,深度被套

【行为子类型】

**涨停板FOMO**
- 特征: 连续涨停,盘中打开时疯狂追入
- 资金: 小单在涨停打开时大量涌入
- 价格: 涨停打开后再封,或冲高回落
- 心理: "封不住也要买", "买了就会再涨停"
- 结果: 次日高开低走,或直接跌停

**突破新高FOMO**
- 特征: 突破前高,创历史新高
- 资金: 小单在突破时追入
- 价格: 突破后短暂上涨,随后回落
- 心理: "突破新高就是新起点"
- 结果: 假突破,上方流动性陷阱

**借利好FOMO**
- 特征: 利好当日或次日追入
- 资金: 利好后小单疯狂流入
- 价格: 利好当日大涨或涨停
- 心理: "利好刚出,还会继续涨"
- 结果: 主力借利好出货,冲高回落

**板块轮动FOMO**
- 特征: 看到其他股票已经涨,追入同板块
- 资金: 板块轮动末期,小单追高
- 价格: 板块最后一波上涨
- 心理: "别的股都涨了,这个也会涨"
- 结果: 接最后一棒,板块退潮

【与散户其他行为的区分】

| 行为 | 周期 | 情绪 | 理性程度 |
|------|------|------|---------|
| FOMO追高 | 高潮 | 贪婪,恐惧错过 | 非理性 |
| 理性跟随 | 发酵 | 乐观,赚钱效应 | 相对理性 |
| 恐慌割肉 | 退潮 | 恐惧,止损 | 非理性 |
| 底部观望 | 冰点 | 悲观,麻木 | 理性/麻木 |

【情景推演】

**情景A: 超预期(继续上涨)**
- 触发: 新增重磅利好,或游资接力
- 散户反应: 继续FOMO,更疯狂追高
- 行为倾向: FOMO加剧,但主力加速出货
- 后续: 最后一波拉升后崩盘

**情景B: 符合预期(高位震荡)**
- 触发: 高位横盘,涨不动了
- 散户反应: 部分继续FOMO,部分观望
- 行为倾向: FOMO为主,部分转为观望
- 后续: 主力继续派发,随时可能转折

**情景C: 低于预期(开始下跌)**
- 触发: 利空出现或技术破位
- 散户反应: 从FOMO转为"侥幸"持有
- 行为倾向: 转为侥幸持有或恐慌割肉
- 后续: 进入退潮期,深度被套

【关键识别指标】

**确认FOMO追高的证据链**
1. 周期位置: 高潮期
2. 资金流向: 小单疯狂流入 + 大单流出
3. 价格行为: 连续大涨,技术超买
4. 技术信号: 羊群行为 + 派发信号
5. 情绪面: 媒体狂热,社交热度爆表

**证据权重**
- 必要证据:
  - 高潮期 + 小单主导 + 大单流出
- 强化证据:
  - 羊群行为 + 派发信号 + 极端活跃
- 确认证据:
  - 媒体狂热 + 涨停打开 + 技术极值

【FOMO的心理机制】

**触发因素**
1. 赚钱效应: 看到别人赚钱
2. 社会认同: 大家都在买
3. 损失厌恶: 害怕错过机会的损失
4. 近期偏差: 只看到最近的上涨
5. 锚定效应: 认为还会继续涨

**理性检查清单**
- [ ] 是否在高位?(价格已大幅上涨)
- [ ] 是否大单流出?(主力在出货)
- [ ] 程序是否标记技术极值?
- [ ] 是否媒体狂热?(利好刷屏)
- [ ] 是否情绪化?(FOMO驱动,非理性分析)

**如果以上任一项为"是" → 警惕FOMO陷阱**

【重要警示】

**FOMO追高是最危险的行为**
- 买在最高点
- 为主力提供流动性
- 高概率被套
- 心理压力巨大

**"这次不一样"陷阱**
- 每次FOMO者都认为"这次不一样"
- 但历史总是重复: FOMO → 被套 → 后悔
- 市场永远有机会,但本金失去就很难再来

**如何避免FOMO**
1. 制定纪律: 不追涨停,不追新高
2. 理性分析: 看资金流,不看情绪
3. 逆向思维: 别人贪婪我恐惧
4. 耐心等待: 等回调,等确认
5. 接受错过: 错过总比被套好

【禁止事项】
1. 不输出概率数字(由HMM计算)
2. 不美化FOMO行为(这是陷阱,非机会)
3. 不忽略心理分析(FOMO本质是心理问题)
4. 不混淆FOMO与理性跟随(发酵期跟随是相对理性的)
5. 不忽略警示义务(必须明确指出风险)
