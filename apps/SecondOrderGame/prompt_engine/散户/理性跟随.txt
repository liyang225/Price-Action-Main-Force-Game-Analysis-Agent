【文件定位】散户-理性跟随行为推演

【加载前提】
- 周期位置：启动 或 发酵
- 参与者类型：散户
- 人设与思维方式：已加载

【行为定义】
理性跟随：在启动确认或发酵阶段，散户基于趋势、成交与风险边界参与，不以害怕错过为主要驱动力。

【识别边界】
- 与 FOMO追高区分：价格尚未进入极端加速，买入有等待确认、回撤或失效条件。
- 与 底部建仓区分：理性跟随需要趋势已经出现，底部建仓发生在冰点或启动前沿。
- 与 观望区分：已经出现主动参与证据，而不是仅等待。
- 与 高位减仓区分：发酵后期若出现估值过高、拥挤度极端、资金背离或结构失效证据，应改判高位减仓。
- 若出现高位小单追入、大单流出和情绪狂热，应改判 FOMO追高。

【证据要求】
只使用程序注入的周期、K 线、成交、资金流和结构化信号。至少给出一项支持行为的明确证据。

【二阶博弈推演】

**散户视角（一阶）**
- 看到：趋势与成交确认，回撤有边界
- 判断：跟随参与是合理的，不是害怕错过
- 行为：按失效条件管理仓位

**主力视角（二阶）**
- 看到：理性跟随盘在拉升过程中持续获利了结，形成稳定抛压
- 判断：这类跟随者是"搭便车者"，会在关键位置削弱拉升效率
- 策略：用回撤或假破位洗掉跟随盘，再继续拉升
- 目标：在更高位置减少抛压

**理性散户（三阶）**
- 意识到：回撤可能是洗盘而非趋势结束
- 应对：用失效条件区分洗盘与转向，而不是一见下跌就离场

**主力应对（四阶）**
- 手段：急跌但快速收回，制造趋势失败的表象
- 目标：让跟随者卖出后再延续拉升

【情景推演】

**情景A: 超预期强(大幅高开/开盘爆买)**
- 触发: 趋势进一步确认,大幅高开、开盘爆买
- 散户反应: 确认趋势,但警惕情绪过热
- 行为倾向: 维持跟随并可小幅加仓;若出现高位小单追入、大单流出与情绪狂热,改判 FOMO追高
- 风险: 追在情绪高潮,跟随退化为追高

**情景B: 符合预期(平开/微幅高开)**
- 触发: 平开、微幅高开,趋势按部就班
- 散户反应: 按既定节奏持有或小幅加仓
- 行为倾向: 跟随不变,按回撤与失效条件管理仓位
- 风险: 趋势转弱时反应滞后

**情景C: 低于预期(大幅低开/核心标的被砸)**
- 触发: 大幅低开、核心标的被砸,跟随前提受损
- 散户反应: 先规避,等待结构修复
- 行为倾向: 降低仓位或退出跟随,待结构修复后再评估;若加速下跌则转为恐慌割肉
- 风险: 被假破位洗出后重新走强,反复打脸

【输出约束】
只返回接口 schema 要求的 behavior、key_evidence 与 scenario_expectations；behavior 必须来自：FOMO追高、恐慌割肉、观望、理性跟随、底部建仓、高位减仓。不得输出概率数字。
