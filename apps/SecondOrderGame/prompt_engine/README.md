# 提示词文件清单

## 概述
本项目的提示词系统分为三层:
1. **通用层** - 4个基础判断模块
2. **参与者层** - 主力6种行为 + 散户3种核心行为
3. **人设与方法论** - 贯穿所有推演的思维框架

所有提示词均输出结构化JSON,使用固定枚举值,明确禁止输出概率数字、博弈信号计算和文件路径选择。

---

## 一、通用层提示词 (`prompt_engine/通用/`)

### 1. 参与者识别.txt
**职责**: 判断当前行为主导者是主力还是散户
**输出**: `{"participant": "主力|散户", "confidence": "高|中|低", ...}`
**核心逻辑**:
- 分离均衡信号(高成本,不可伪造) > 混同均衡信号(可伪造)
- 大单流向 + 博弈信号 + 周期位置三者自洽性检验

### 2. 人设与思维方式.txt
**职责**: 定义二阶博弈推演的基本立场与方法论(所有推演提示词的前置加载)
**核心原则**:
- 你是概率管理者,不是预测者
- 共识的诅咒: 信号成为共识后不仅失效,反而成为反向收割工具
- 序贯理性: 主力预判散户反应,散户预判主力意图
- 四种思维方式: 二阶思维、情绪钟摆、参与者博弈、概率树

### 3. 主体目的分析.txt
**职责**: 识别消息事件背后发布方的真实意图
**输出**: `{"message_type": "利好公告|利空公告|...", "true_purpose": "...", "signal_type": "分离均衡|混同均衡", ...}`
**典型模式**:
- 借利好出货: 高位利好 + 大单流出 + 小单接盘
- 制造恐慌吸筹: 低位利空 + 大单流入
- 政策暖风托底: 明确政策 + 国家队ETF放量

### 4. 情绪周期判断.txt
**职责**: 判断板块处于情绪钟摆的哪个位置
**输出**: `{"cycle_position": "冰点|启动|发酵|高潮|退潮", "cycle_event": "无|平台整理|二次启动|加速|高位兑现|破位转弱", "consensus_state": "一致|分歧", "consensus_direction": "转强|转弱|未确认", ...}`
**五档定义**:
- 冰点: 极度悲观,成交萎缩,主力建仓试盘
- 启动: 底部反转,趋势待确认,主力震仓洗盘
- 发酵: 上升趋势确立,赚钱效应扩散;高潮后的高位平台若趋势和核心未破也归入发酵
- 高潮: 加速或极端亢奋,不由固定连板数或停留天数决定
- 退潮: 高位兑现后强度转弱;平台横盘本身不等于退潮

**重要**: 板块共识状态(一致/分歧)是正交字段,不是周期位置!

## 二、主力行为提示词 (`prompt_engine/主力/`)

### 1. 建仓.txt
**周期**: 冰点
**行为**: 隐蔽吸筹,分批建仓
**资金特征**: 大单持续小幅流入,换手率低
**价格特征**: 底部横盘或阴跌,不明显拉升
**子类型**: 试探建仓、主动吸筹、逆势建仓(配合利空)

### 2. 震仓.txt
**周期**: 启动/发酵
**行为**: 洗盘清洗浮筹,降低拉升成本
**关键特征**: 大单流出后**快速回流**,价格**快速回升**(1-3日)
**与出货的区分**: 震仓有回流+回升,出货持续流出+不回升
**子类型**: 技术回调震仓、制造恐慌震仓、配合利空震仓、反复震仓

### 3. 拉升.txt
**周期**: 发酵/高潮
**行为**: 推动价格上涨,吸引跟风
**资金特征**: 大单持续流入,小单跟随
**价格特征**: 明显上涨,连续阳线,创新高
**子类型**: 稳步拉升(发酵期)、加速拉升(高潮期)、借利好拉升
**警示**: 高潮期末拉升随时可能转为出货

### 4. 出货.txt
**周期**: 高潮/退潮
**行为**: 派发筹码,兑现利润
**关键特征**: 大单流出 + 小单接盘,涨停打开,冲高回落
**与震仓的区分**: 出货大单**不回流**,价格**不回升**
**子类型**: 高位派发、借利好出货、打压出货(退潮期)、尾盘拉升次日出货

### 5. 观望.txt
**周期**: 任意
**行为**: 暂时不动,等待时机
**资金特征**: 大单流入流出平衡,程序标记低活跃
**各周期原因**:
- 冰点: 等待更低价位或建仓时机
- 启动: 趋势未确认
- 发酵: 短暂休整
- 退潮: 等待冰点形成

### 6. 狩猎止损.txt
**周期**: 退潮(主要)
**行为**: 主动触发散户止损单,下方接筹
**三阶段**: 探测止损密集区 → 驱动价格触发止损 → 接收恐慌筹码
**关键特征**: 跌破支撑后**V型反转**,长下影线,1-2日完成
**与打压出货的区分**: 狩猎止损有大单回流+快速回升,出货持续下跌

## 三、散户行为提示词 (`prompt_engine/散户/`)

### 1. FOMO追高.txt
**周期**: 高潮
**行为**: Fear Of Missing Out,非理性追涨
**资金特征**: 程序标记小单主导流入,大单流出
**心理机制**: 赚钱效应、社会认同、损失厌恶、近期偏差
**子类型**: 涨停板FOMO、突破新高FOMO、借利好FOMO、板块轮动FOMO
**警示**: 最危险的行为,买在最高点,为主力提供流动性

### 2. 恐慌割肉.txt
**周期**: 退潮
**行为**: 非理性止损,低位情绪化卖出
**资金特征**: 程序标记小单主导流出,大单可能流入(狩猎止损)
**心理机制**: 亏损厌恶、恐惧放大、从众心理
**子类型**: 追高被套恐慌割肉、止损触发恐慌割肉、利空恐慌割肉、跟风恐慌割肉
**警示**: 第二大陷阱,卖在恐慌最严重时,容易卖在底部

### 3. 观望.txt
**周期**: 任意
**行为**: 不操作,等待信号(可能理性或非理性)
**子类型**:
- **理性等待观望**: 发酵/高潮期等回调(合理)
- **迷茫观望**: 启动期看不懂方向(可理解)
- **麻木观望**: 冰点期失去兴趣(不合理)
- **侥幸观望**: 退潮/冰点期被套后被动持有(最危险)

**特别说明"侥幸"观望**:
- 不是真正的观望,而是被套后的被动持有
- 心理: "万一反弹呢","都亏这么多了"
- 后果: 深度被套,错过底部(解套即卖)

理性跟随、底部参与和高位减仓只作为核心行为的反向证据或低优先级对照，不建立独立核心提示词，也不占用生产行为路由。

## 四、提示词设计原则

### 1. 结构化输出
所有提示词均输出严格的JSON格式,字段名称固定,值使用枚举:
```json
{
  "behavior": "建仓",
  "confidence": "高",
  "key_evidence": [],
  "scenario_expectations": {}
}
```

### 2. 三禁止
- **禁止输出概率数字**: 由程序HMM计算,模型只输出推理逻辑
- **禁止计算博弈信号**: 程序已计算完成,模型只引用结果
- **禁止选择文件路径**: 由路由器决定,模型不参与

### 3. 情景树结构
每个行为推演包含三情景应对:
- 超预期: 利好/强于预期
- 符合预期: 趋势延续
- 低于预期: 利空/弱于预期

### 4. 二阶博弈推演
标准四层推演:
- 一阶: 散户视角
- 二阶: 主力视角(看到散户会如何反应)
- 三阶: 理性散户(意识到主力意图)
- 四阶: 主力应对(知道散户发现了)

### 5. 证据权重分层
- 必要证据: 缺一不可
- 强化证据: 提高置信度
- 排除证据: 否定当前判断
- 反向证据: 降低置信度

### 6. 关键行为区分
明确写明易混淆行为的区分方法:
- 震仓 vs 出货: 大单是否回流,价格是否回升
- 狩猎止损 vs 打压出货: 是否V型反转,是否长下影线
- FOMO追高 vs 理性跟随: 周期位置(高潮 vs 发酵)
- 恐慌割肉 vs 理性止损: 情绪驱动 vs 判断驱动

## 五、使用流程

**程序调用顺序**:
1. 加载 `人设与思维方式.txt` (所有推演的基础)
2. 并行调用:
   - `情绪周期判断.txt` → 确定周期位置
   - `参与者识别.txt` → 确定主导者
3. 根据(周期 + 参与者)路由到对应行为提示词
4. 材料预分析阶段在有缓存消息时调用 `主体目的分析.txt`，结构化结果写回当日材料缓存
5. 后续情绪周期、参与者识别和行为推演读取包含主体目的的完整材料
6. 程序收集所有模型输出 → HMM计算概率 → 生成最终决策

**示例**:
- 周期=高潮 + 参与者=散户 → 加载 `散户/FOMO追高.txt`
- 周期=退潮 + 参与者=主力 → 加载 `主力/狩猎止损.txt`
- 周期=冰点 + 参与者=主力 → 加载 `主力/建仓.txt`

## 六、与PA_Agent技术分析系统的联动

本系统(SecondOrderGame)专注**参与者意图推演**,PA_Agent专注**技术形态识别**,两者通过接口联动:

**本系统输出**:
- 参与者类型(主力/散户)
- 行为推演(建仓/震仓/拉升/出货/观望/狩猎止损 等)
- 情绪周期位置
- 情景应对树

**PA_Agent输出**:
- 技术形态(趋势/通道/区间/尖峰)
- 入场信号(信号棒/入场棒/确认棒)
- 三价(entry/stop/take_profit)
- 风险收益比

**联动逻辑**:
- 本系统识别"主力出货" + PA识别"假突破" → 不追突破
- 本系统识别"狩猎止损"（主力下方接筹，前视反弹确认）→ 底部买入机会
- 本系统识别"下方流动性陷阱"（破位下跌延续，看跌）→ 下跌警示
- 本系统识别"FOMO追高" + PA识别"派发信号" → 高风险警示

**关键区分**:
- 技术形态(PA): 假突破 → 中性描述
- 参与者意图(本系统): 流动性陷阱 → 主力收割工具
