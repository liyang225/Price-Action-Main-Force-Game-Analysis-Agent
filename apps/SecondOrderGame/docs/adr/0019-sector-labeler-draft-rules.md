# ADR-0019：板块层标注器规则草案

**状态**：草案（待实测验证）
**日期**：2026-08-10
**决策者**：架构设计阶段
**影响范围**：P0-4 板块层标注器、HMM 混淆矩阵 C 的数据积累

> **历史状态：已被 ADR-0021 取代。** 本文保留当时的 OHLCV 草案和审计记录；当前周期枚举为冰点/启动/发酵/高潮/退潮，分歧是正交的板块共识状态。

---

## 背景

P0-4 需要板块层标注器将板块指数 OHLCV 映射为五档情绪周期位置（冰点/启动/分歧/高潮/退潮）。个股层已有实测冻结的规则（ADR-0017），但板块层尚无。

**核心约束**：判定必须直接从板块指数 OHLCV 出发，**不能用情绪指数（`sentiment.yaml` 的 0-100 数值）做阈值映射**。理由：

- 情绪指数是给人看的解释性数值
- 若用它推导周期档位，混淆矩阵 C 会退化成恒等映射
- 这是"大模型是噪声传感器"设计的核心——大模型输出标签，经 C 矩阵折算为对隐状态的观测证据
- 用指数切五段 = 把隐状态定义为指数的确定性函数，C 矩阵变成单位阵，整个 HMM 滤波失效

这是最容易走的捷径（情绪指数刚好是个现成的连续数值），必须在规则设计时明确拒绝。

---

## 决策

### 1. 板块层判定方法论

板块层判定情绪周期档位 ≠ 个股层判定主力行为，方法论匹配对象：

| 层 | 判定对象 | 前向收益口径 | 窗口长度 | 关键特征 |
|---|---|---|---|---|
| 个股层 | 主力意图 | **超额收益**（相对板块） | 5 日 | 量价背离、支撑突破、影线 |
| 板块层 | 周期位置 | **绝对收益** | 10 日 | 状态持续性、位置、连续性 |

**为什么窗口更长**：板块由多只个股加权，单日噪音被平滑，转折确认需要更长周期。实测时若 10 日过长（覆盖率过低），可降至 7 日，但不应低于个股的 5 日。

**为什么用绝对收益**：板块本身就是基准，无需再减外部基准。

### 2. 五档规则的设计逻辑

按特异性从高到低：

#### **冰点**（底部特征，特异性最高）
```
价格在 20 日区间下 30%
+ 连续 5 日缩量
+ 进入前 5 日弱势或横盘
+ 前向 10 日开始反弹（>= 3%）
```
**理论依据**：钟摆极端 + 主力吸筹迹象（缩量盘整） + 前向验证转折

#### **高潮**（顶部特征，特异性最高）
```
当日大涨（>= 3%）
+ 爆量（>= 1.8 倍）
+ 价格在 20 日区间上 30%
+ 进入前 5 日已大涨（>= 8%）
+ 前向 10 日涨幅收窄或转负（<= 2%）
```
**理论依据**：FOMO 追高 + 量价背离（爆量但前向失速） + 钟摆极端

#### **分歧**（多空拉锯，中等特异性）
```
当日涨跌幅小（<= ±2%）
+ 前向 10 日收益中性（<= ±3%）
+ 放量（>= 1.2 倍）
+ 近期波动率高（≥ 1.5%/日）
```
**理论依据**：高换手 + 方向不明 = 多空力量均衡

#### **启动**（方向明确向上）
```
当日微涨或平（>= 0.5%）
+ 前向 10 日涨幅 >= 5%
+ 温和放量（0.9 - 1.8 倍）
+ 摆脱底部区域（价格位置 >= 40%）
+ 近期无连续下跌
```
**理论依据**：趋势确立 + 资金流入 + 未到极端

#### **退潮**（恐慌杀跌）
```
当日跌（<= -2%）
+ 前向 10 日跌幅 >= 4%
+ 放量
+ 跌离高位（价格位置 <= 60%）
+ 连续下跌至少 2 日
```
**理论依据**：情绪逆转 + 恐慌离场

### 3. 优先级

```
priority: [冰点, 高潮, 分歧, 退潮, 启动]
```

两极（冰点、高潮）特征最特异，优先判定；分歧次之（同时要求量价背离）；启动、退潮为方向性状态。

### 4. 新增特征（相对个股层）

板块层引入"状态持续性"特征（个股层没有）：

- `consecutive_down_days`：连续下跌日数（最多回溯 20 日）
- `consecutive_shrink_days`：连续缩量日数（最多回溯 20 日）
- `price_position_20`：价格在 20 日区间的位置
- `recent_trend_5d`：进入状态前的 5 日累计收益

**理由**：板块转折比个股慢，需要"已持续 N 日"这类累积证据确认状态，而非单日突变。

## 被拒方案

### 方案 A：用情绪指数切五段

```yaml
# ❌ 被拒
冰点: sentiment_index <= 20
启动: 20 < sentiment_index <= 40
分歧: 40 < sentiment_index <= 60
高潮: 60 < sentiment_index <= 80
退潮: 80 < sentiment_index
```

**拒绝理由**：
1. 混淆矩阵 C 退化成恒等映射（真实档位 = 大模型输出）
2. "大模型是噪声传感器"的设计失效
3. 情绪指数本身是派生值（由消息面 + 行情面计算），用它推周期档位 = 循环定义

### 方案 B：复用个股层规则

直接套用个股层的六种行为（建仓/震仓/拉升...）到板块。

**拒绝理由**：
1. 语义不匹配：板块没有"主力建仓"这个概念（板块是加权指数，不是可操纵对象）
2. 判定对象不同：个股层判定"意图"，板块层判定"周期位置"
3. 前向收益口径不同：个股用超额，板块用绝对

### 方案 C：不要标注器，只用先验

永远不积累标签，混淆矩阵 C 永远是手写先验。

**拒绝理由**：
1. 违反"让数据逐步接管先验"的核心设计
2. 冷启动期无限延长
3. 无法通过校准度评估系统是否在退化

## 后果

### 正面

1. **清晰区分两层判定对象**：个股判意图，板块判位置
2. **保护混淆矩阵的作用**：C 矩阵不退化，大模型输出与真实档位有可测量的映射关系
3. **可实测验证**：规则明确，可用 50-100 个人工标注样本验证阈值合理性

### 负面与风险

1. **阈值未实测**：当前为理论推导，实际覆盖率、命中分布未知
2. **可能需要多轮调整**：首次实测后大概率需调阈值（个股层也经历了多次迭代）
3. **窗口长度的权衡**：10 日可能过长（覆盖率低）或过短（噪音大），需实测确认

### 待办

**P0-4 实施时的步骤**（交给工程师前你需要完成）：

1. **采集板块指数历史 OHLCV**
   - 富途 `get_history_kline`，板块代码如 `SH.BK0735`（半导体）、`SH.BK0727`（医疗服务，已核对）
   - **⚠ 其余代码需先核对**：用户提示新能源汽车等代码未验证，P0-4 实证前必须用 API 确认每个板块代码
   - 时间范围：至少覆盖 2 年（一个完整牛熊周期）
   - 板块数：至少 5 个不同行业

2. **人工标注 50-100 个板块日**
   - 跨五档均衡分布（每档 10-20 个）
   - 分散时间：牛市顶部、熊市底部、震荡期各覆盖
   - 标注标准：凭直觉判断"这一天该板块处于哪个情绪档位"

3. **用草案规则跑机器标注**
   - 统计命中分布 vs 人工标注的一致性
   - 计算混淆矩阵（人工标注为真值，机器标注为观测）
   - 识别系统性偏差（如机器把所有"启动"都误判成"分歧"）

4. **调整阈值**
   - 使机器标注的边际分布逼近人工标注
   - 不追求 100% 一致（那是过拟合），目标是合理覆盖五档 + 可解释的混淆模式

5. **冻结规则**
   - `version: 0 → 1`
   - 计算 `rule_hash`（本文件的 SHA256）
   - 标记为生产就绪，后续改动走 ADR 流程

## 与个股层的对比

| 项 | 个股层（ADR-0017） | 板块层（本 ADR） |
|---|---|---|
| 判定对象 | 主力行为（建仓/震仓/拉升/出货/观望/狩猎） | 情绪周期位置（冰点/启动/分歧/高潮/退潮） |
| 前向收益 | 超额收益（相对主板块） | 绝对收益 |
| 前向窗口 | 5 个交易日 | 10 个交易日（草案，可调至 7） |
| 关键特征 | 量价背离、支撑突破、影线 | 状态持续性、连续性、位置 |
| 实测状态 | ✅ 已冻结（94,594 个股票日） | ⏳ 草案（待 50-100 个板块日验证） |
| 覆盖率 | 26.99%（实测） | 未知（目标 35-50%） |
