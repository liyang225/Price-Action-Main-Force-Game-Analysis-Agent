# 博弈信号由程序计算，大模型不参与信号数值生成

纳什均衡带、逆势信号、动量信号、纳什回归信号均由 Python 程序按固定公式从价格与成交量数据计算，不经大模型。这延续了 PA_Agent "程序决定步骤与数据，LLM 只做结构化判断"的核心架构原则，并与 ADR-0001（大模型合法角色仅限离散标签输出）一致。

## 信号定义（程序实现，不得修改为 LLM 生成）

**纳什均衡带**：以短周期均值为中心，以标准差乘偏差率为半径的价格区间。参数（周期长度、偏差率）来自配置文件，不硬编码。

**逆势信号**：
```
逆势买入 = 羊群卖出 AND (吸筹信号 OR 下方流动性陷阱)
逆势卖出 = 羊群买入 AND (派发信号 OR 上方流动性陷阱)
```

**动量信号**：
```
动量买入 = 价格在均衡带下方 AND 聪明钱指数为正 AND NOT 羊群买入
动量卖出 = 价格在均衡带上方 AND NOT 聪明钱指数为正 AND NOT 羊群卖出
```

**纳什均衡回归信号**：
```
回归买入 = 价格在均衡带下方 AND 当根收盘 > 前根收盘 AND 成交量 > 均量
回归卖出 = 价格在均衡带上方 AND 当根收盘 < 前根收盘 AND 成交量 > 均量
```

## 大模型的合法介入点

大模型可以对信号做**解释**（"当前纳什均衡带下方逆势买入信号，因为成交量异常 + 聪明钱净流入"），但不得生成或修改信号数值本身。信号在注入大模型提示词时以已计算完毕的结构化字段形式注入，大模型只读，不写。

## 可视化

二阶博弈使用独立 K 线图组件，不修改 PA 的通用图表。图中不显示 EMA20；纳什均衡带以上界浅蓝虚线、下界浅绿虚线、中枢线浅金橙色虚线呈现。逆势时点使用金橙色空心三角形，流动性陷阱使用红色十字，聪明钱活跃使用蓝色圆圈内白色「聪」字，标记放在对应 K 线收盘位置的上方或下方。

图表序列计算当前加载的全部已收盘 `K_120M`，逐点只读取该点及此前数据，不允许未来数据泄漏。纳什均衡带使用最近 16 根 K 线（8 个交易日）的统计窗口。该序列只用于图表呈现，不进入大模型；大模型与界面分析结论仍只消费最新一根已收盘 K 线的单点博弈信号。可视化是信号的呈现，不影响信号计算与推演契约。
