# 情绪周期档位取五档，"侥幸"是行为描述而非独立档位

原始需求列出了八个候选档位：冰点、分歧、升温、降温、中性观望、侥幸、高潮、退潮。设计过程中收敛为五档：冰点、启动、分歧、高潮、退潮。

## 收敛理由

**升温/降温合并为启动/退潮**：升温就是从冰点向高潮运动的过程，与"启动"同义；降温就是从高潮向冰点运动，与"退潮"同义。保留方向性名称（启动/退潮）更清晰，避免与"分歧期的小幅回调"混淆。

**中性观望合并到分歧**：分歧期的核心特征就是多空均衡、方向不明，"中性观望"是分歧期散户的行为描述，不是独立的情绪档位。

**侥幸不是档位**：侥幸是"退潮期 + 羊群散户未离场"的行为特征，是一种情绪周期内的参与者行为状态，而不是情绪周期本身处于哪个位置。将侥幸定义为独立档位会产生语义混乱——情绪可以在任何档位出现侥幸心理，尤其在退潮期最典型。

## 五档定义

- **冰点**：极度悲观，成交量萎缩，价格长期横盘或下跌
- **启动**：情绪开始回暖，出现方向性信号，资金小量流入
- **分歧**：多空博弈激烈，走势震荡，方向未定
- **高潮**：情绪极度乐观，成交量放大，FOMO 追高普遍
- **退潮**：情绪急转直下，恐慌卖出，筹码换手

## HMM 状态空间

五档直接作为 HMM 隐状态空间，无需另设"中间状态"。五档的 Dirichlet 转移矩阵可识别性优于八档（参数更少，所需样本量更低）。
