# B 类概率使用下一完整 K_120M 时段收益

## 背景

B 类概率原实现把两个决策点都按「下一根 K 线开盘价相对当前收盘价」计算。午盘场景因此实际测量的是 13:00 开盘相对 11:30 收盘的午休跳变，而不是下午时段走势。

项目内 60 只 A 股、约 9.5 万个交易日的 K_120M 样本显示，在固定正负 1% 边界下：午休开盘跳变有 99.79% 落入中间区间；改用下午收盘相对上午收盘后，中间区间占 69.52%，上下两侧分别占 15.71% 和 14.77%。生产记录中出现的 99.70%「符合预期」因此不是可靠预测，而是观测变量退化。

## 决策

B 类概率统一描述决策点之后的下一完整 K_120M 时段：

- 午盘 `intraday_next_bar`：`当日下午收盘 / 当日上午收盘 - 1`
- 收盘 `overnight_next_bar`：`次日上午收盘 / 当日下午收盘 - 1`

收盘口径自然包含隔夜跳空与次日上午盘中变化。两个决策点继续使用独立样本总体和独立随机数状态。

为兼容既有 T+1 闸门、历史记录和 PA 界面，`OpeningDistribution*` 类型名、`ProbabilityType.OPENING_RANGE` 以及 `gap_down / near_reference / gap_up` outcome 暂不重命名；它们是接口标识，不再定义生产语义。界面对用户统一显示「下一完整时段概率」。概率配置版本由 1 升至 2。

## 后果

- 午盘情景不再被午休价格连续性机械压入「符合预期」。
- 收盘情景覆盖完整次日上午，而不只覆盖集合竞价跳空。
- 旧分析记录仍可展示，但其配置版本 1 与新版配置版本 2 不可直接比较。
- 固定区间是否需要按品种波动率自适应，必须另行用样本外 Brier score 校准；不得用概率上限或下限美化输出。

## 实施补充（应对树卡片措辞）

B 类改为「下一完整时段」口径后，PA 侧应对树卡片一度只显示情景名 + 百分数（「超预期强 44.0%」），使用者会把它读成「次日大幅高开 44.0%」。已在 PA 界面补齐口径标注，**不改变任何概率计算**：

- 卡片上方固定说明：数字为 B 类历史样本频率（次日上午收盘相对今日收盘的完整时段收益分桶），不是次日开盘跳空预测；
- 每张卡片标注分桶边界：超预期强 ≥ +1%（含低开高走）／符合预期 -1%~+1%／低于预期 ≤ -1%；
- 原「下一时段概率」小标题改为「历史样本频率」。

改动位置：`PA_Agent6.24/PA_Agent/pa_agent/gui/second_order_cards.py`（`_ScenarioCards`）、`figma_rebuild/generate_three_figma_svgs.py`、`figma_rebuild/二阶博弈_应对树.svg`（设计稿文案）与 `PA_Agent/tests/unit/test_second_order_cards.py`。情景名与 `gap_up / near_reference / gap_down` 契约标识保持不变。
