# HMM 参数工作台

## 启动

在项目根目录运行：

```powershell
python -m src.gui.workbench
```

界面读取 `config/hmm_prior.yaml`。打开、切换模式和预览都不会写磁盘；只有点击“校验并保存”且完整配置通过生产校验后才会原子写入。

## 编辑模型

- 新手模式：选择 A、C 或 W 的任一概率行，用中文百分比滑块调整。同行其他值按原结构补偿到 100%；弱/中/强分别映射到合法 alpha 3、8、24。
- 专家矩阵：直接编辑 A、C、W 的全部概率和 alpha。非法值留在未保存草稿中并显示原因，保存被禁用，上一个合法配置仍被单独保留。
- 实时预览：热力图直接展示未保存草稿；行为分布复用生产 `HMMFilter` 的前向更新与行为预测，不维护第二套公式。
- 版本历史：合法保存自动把版本加一并保留最近十个快照。恢复旧快照会先校验，再形成新的版本事件。

## 测试边界

自动测试覆盖三个公共接缝：`ConfigSession`、`ConfigHistory`、`build_preview`，以及保存、滑块联动和非法专家输入等关键 Qt 交互。视觉行为采用人工验收：960×620 与 1440×900 两档窗口、键盘焦点、文字与颜色并用、滚动区域、Windows 字体回退。

当前项目环境实际提供 PyQt6 6.11，因此实现沿用 PA Agent 已有的 PyQt6 运行时；界面只使用 Qt 原生控件与绘制 API，不引入额外 matplotlib 依赖。
